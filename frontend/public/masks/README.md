# Optional 3D mask GLB files

Place `.glb` files here to override procedural 3D masks:

- `dog-ears.glb` — Dog mask
- `crown.glb` — Crown mask
- `glasses.glb` — Glasses mask

If a file is missing, ZoneMeet uses built-in procedural 3D geometry (Three.js + Kalidokit).

Export from Blender as GLB, scale ~0.35, centered on face anchor.
